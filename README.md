# New Year Countdown

JavaScript countdown to the next New Year with a matching target-year label and automatic local-time rollover.

Part of my JavaScript practice work. Explore my complete projects on [GitHub](https://github.com/awaljanhematyar) or my [developer portfolio](https://hematyar-professional-portfolio.vercel.app/).

[Live demo](https://awaljanhematyar.github.io/countdown-timer/)

## Features

- Calculate the next New Year using the visitor's local timezone.
- Display days, hours, minutes and seconds.
- Keep the displayed target year aligned with the countdown.
- Roll to the following year automatically.

## Run locally

```sh
git clone https://github.com/awaljanhematyar/countdown-timer.git
cd countdown-timer
```

Serve the folder using VS Code Live Server and open `index.html`. There is no npm installation or build step. Use a modern browser.
